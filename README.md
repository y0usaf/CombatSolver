# Combat Solver, fair fork

A fork of [Combat Solver](https://github.com/Torch1230/CombatSolver) by Torch1230 that makes it fair: the solver plans only from what the player can see, and resamples hidden RNG, draw order and enemy moves before each decision. The UI is a single Auto on/off toggle.

All the solver work is upstream's. The combat simulation core adapts [Random Foreseer](https://github.com/hotwords123/StS2.RandomForeseer) by hotwords123. MIT; see [LICENSE](LICENSE) and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
